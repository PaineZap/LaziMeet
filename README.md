# LaziMeet - Nền tảng họp trực tuyến GenZ

LaziMeet là ứng dụng họp trực tuyến (Video Conference) hoàn toàn chạy trên trình duyệt web, sử dụng **WebRTC** và **PeerJS Cloud** (Signaling miễn phí). Giao diện mang phong cách GenZ năng động, hiện đại và trẻ trung với tông màu gradient rực rỡ.

## 🌟 Tính năng nổi bật
- **100% Client-side**: Không cần cài đặt backend, server riêng hay cơ sở dữ liệu phức tạp.
- **Hoạt động trên GitHub Pages**: Có thể đưa lên GitHub và bật GitHub Pages chỉ trong 1 phút.
- **WebRTC P2P Video/Audio**: Kết nối video và âm thanh trực tiếp chất lượng cao giữa nhiều người tham gia.
- **Chia sẻ màn hình**: Hỗ trợ trình bày slide, màn hình máy tính trực tiếp trong phòng họp.
- **Chat trực tiếp**: Gửi tin nhắn trao đổi trong phòng.
- **Danh sách thành viên**: Quản lý người tham gia dễ dàng.

## 🚀 Hướng dẫn đưa lên GitHub Pages (Nhanh chóng & Miễn phí)

1. **Tạo Repository mới trên GitHub**:
   - Truy cập [GitHub](https://github.com) và tạo một repository công khai mới (Public), ví dụ đặt tên là `lazimeet`.

2. **Upload các file**:
   - Tải toàn bộ các file sau vào repository:
     - `index.html`
     - `style.css`
     - `script.js`
     - `README.md`

3. **Bật GitHub Pages**:
   - Trong repository của bạn trên GitHub, chọn tab **Settings**.
   - Ở menu bên trái, chọn **Pages**.
   - Tại mục **Build and deployment -> Branch**, chọn nhánh `main` (hoặc `master`) và thư mục `/ (root)`, sau đó nhấn **Save**.
   - Sau 1-2 phút, GitHub sẽ cung cấp cho bạn một đường dẫn (ví dụ: `https://username.github.io/lazimeet/`). Truy cập đường dẫn đó để sử dụng LaziMeet!

## 🛠️ Công nghệ sử dụng
- **HTML5 & CSS3**: Giao diện Glassmorphism, Responsive, GenZ Colorful Theme.
- **JavaScript (ES6+)**: Xử lý logic thời gian thực.
- **WebRTC & PeerJS Cloud**: Truyền tải âm thanh/video P2P không qua trung gian server lưu trữ.
